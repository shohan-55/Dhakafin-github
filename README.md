# DhakaFin Premium SaaS Website Starter

This repository has been initialized as a Laravel foundation for a premium DhakaFin fintech/SaaS website.

## Stack
- Laravel 11
- Blade templates
- Custom premium UI styling
- GSAP motion support
- cPanel-ready deployment structure

## Setup
1. Run `composer install`
2. Copy `.env.example` to `.env`
3. Generate app key: `php artisan key:generate`
4. Start local server: `php artisan serve`

## Files created
- `resources/views/home.blade.php` — premium landing page
- `public/css/app.css` — custom design system
- `public/js/app.js` — motion finishing touches
- `routes/web.php` — home route

## Notes
This is the starter foundation and can be expanded into a complete SaaS site with:
- multi-page marketing site
- admin login/dashboard
- client portal
- document vault
- calculators
- CRM workflows
