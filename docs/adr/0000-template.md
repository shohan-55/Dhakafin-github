## Context

What is true about the situation that forces a decision. Include the constraint
that actually bites — budget, skill, deadline, regulation, a dependency nobody
controls. If the context would be obvious to anyone in six months, delete it;
this section exists for the parts that will not be.

## Decision

What we are doing, stated so that someone can disagree with it.

## Consequences

**Positive** — what this buys.

**Negative** — what this costs. Be specific and honest; an ADR with no negative
consequences is marketing, not engineering. Include what we now cannot easily do.

**Neutral** — what changes without being better or worse.

## Alternatives considered

Each with the reason it lost. "We didn't think of it" is not a reason — if that is
the truth, say the decision is provisional.

## Review trigger

The condition under which this should be revisited. An ADR with no review trigger
is a decision pretending to be permanent.
